# 卷二 · 情感几何学：三维心路坐标系

## 摘要

六型人格不是孤立标签，而是一个能描绘**完整的人**的三维坐标系。
所有偏移都是空间中的坐标移动。

## 一、坐标系定义

**X 轴 · 时间轴（过去 ↔ 未来）**【实测】

```
  旧人型 X = −1.0（锚定过去）  ←→  空灵型 X = +1.0（锚定未来）
  （其余四型 X = 0）
```

**Y 轴 · 情绪温度轴（冷 ↔ 热）**【实测】

```
  温暖型 Y = +1.0 ｜ 冷感型 Y = −1.0
  张力型 Y = 0 ｜ 锋利型 Y = 0
  ★ 张力与锋利在温度轴上**同值** —— 这正是"两条轴不够"的证明，所以要第三条轴。
```

**Z 轴 · 稳定度轴（稳 ↔ 不稳）**【待验假设】

```
  冷感 0.9 ｜ 旧人 0.8 ｜ 温暖 0.5 ｜ 空灵 0.4 ｜ 锋利 0.3 ｜ 张力 0.1

  ★★ 口径（比我写的那六个数更要紧）：
     这六个数是**按六型在项目里的既有稳定性排序给的初值**，
     源码里原话是「**【我给的初值，等他按实测改】**」——
     **它还没被任何实测数据校准过。**
     → 请把它当**待验假设**读，**不要当定义引用**。
     → 校准方法：用真实互动数据里"同一型在不同轮次的波动幅度"去回归。
```

## 二、动态偏移：坐标变换与韧性动力学

**撞击与位移**【实测】
外部事件（落选、被批评）产生撞击，坐标点从 A 移动到 B。
偏移向量包含：**方向**（更冷／更软／更攻击／更逃／更僵）、**幅度**（0–10）、**心路秒数**。

```
  ★ 一个必须写清的细节：**「更僵」的位移向量是零向量** ——
    它表示"原地冻结"，即"坐标不动"。
    → 所以"更僵"**不是**"往某个方向走了"，而是"**没有位移**"。
    （这一点搞错的话，后面所有关于"僵"的推理都会反。）
```

**轨迹判定**【推断】

```
  正常人的轨迹应是波浪形（像心电图）；
  而向某一边界持续偏移的直线轨迹，是另一种状态。
  ★ 口径：这是**判据的方向**，不是已测出的阈值 —— 目前没有临床或统计校准。
```

**核心洞察**【实测，但样本小】

```
  实测四参数：撞击强度 / 情绪幅度 / 动作变形率 / 心路秒数
  ★ 一句判据（用户定的、写进了代码注释）：
     「**"疼得多"不扣分，"不想了就动"才扣分**」
     → 即：情绪幅度本身不惩罚，**心路秒数骤降 + 动作变形**才惩罚。
  ⚠️ 样本量：这一条的实测来自**有限的几轮**，不是大规模统计。
```
