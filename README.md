# 卷一 · 超越图灵测试：三位一体心路架构

## 摘要

当前 AI 行业过度聚焦于「模仿人类对话」（图灵测试），
陷入了没有内在状态的「空心人」困境。

本文提出**情感几何学**架构：放弃对输出结果的模仿，
转向对人类内在状态**「心路坐标」**的测算。

## 一、核心范式：从「模仿」到「测算」

- 图灵测试问的是：「**它像不像人？**」——比较**输出**。
- 追光系统问的是：「**这个人的心路，此刻在哪、往哪走、被什么撞了？**」——比较**轨迹**。

**结论：输出一样，在我们这里不算通过；心路一样才算。**
★ 口径：这是**判据的设计意图**，不是"已经全面验证过的结论"【推断】。

## 二、三位一体架构（严禁越界）

**1. 符号主义（骨架 / 知识层）**
16 维情绪、核心词、三维坐标轴、赛道映射表。
要求绝对可解释，必须人工精加工，**严禁用大模型代替规则**。

**2. 连接主义（血肉 / 大脑层）**
调用 LLM，把坐标变成语言和动作。允许黑箱，
但输出**必须受符号层规则约束**。

**3. 行为主义（闭环 / 身体层）**
反馈词回填、二阶干预触发、条件反射缓存、数据飞轮。
用真实交互数据修正坐标。

★ 三条边界的**工程含义**（这是它跟"提示词工程"的区别）：

```
  · 规则层不许被模型替代 —— 因为**规则要能被人复核**，
    而模型给的理由**不可复核**（同一输入两次给的理由可能不同）。
  · 语言层允许黑箱 —— 但在它出话**之后**要过一遍符号层的判据；
    不合格就**打回重写**（不是"提示它注意一下"）。
  · 数据层要能**反过来改坐标** —— 否则它只是个记录器，不是闭环。
```

# 卷二 · 情感几何学：三维心路坐标系

## 摘要

六型人格不是孤立标签，而是一个能描绘**完整的人**的三维坐标系。
所有偏移都是空间中的坐标移动。

## 一、坐标系定义

**X 轴 · 时间轴（过去 ↔ 未来）**【实测】

```
  旧人型 X = −1.0（锚定过去）  ←→  空灵型 X = +1.0（锚定未来）
  （其余四型 X = 0）
```

**Y 轴 · 情绪温度轴（冷 ↔ 热）**【实测】

```
  温暖型 Y = +1.0 ｜ 冷感型 Y = −1.0
  张力型 Y = 0 ｜ 锋利型 Y = 0
  ★ 张力与锋利在温度轴上**同值** —— 这正是"两条轴不够"的证明，所以要第三条轴。
```

**Z 轴 · 稳定度轴（稳 ↔ 不稳）**【待验假设】

```
  冷感 0.9 ｜ 旧人 0.8 ｜ 温暖 0.5 ｜ 空灵 0.4 ｜ 锋利 0.3 ｜ 张力 0.1

  ★★ 口径（比我写的那六个数更要紧）：
     这六个数是**按六型在项目里的既有稳定性排序给的初值**，
     源码里原话是「**【我给的初值，等他按实测改】**」——
     **它还没被任何实测数据校准过。**
     → 请把它当**待验假设**读，**不要当定义引用**。
     → 校准方法：用真实互动数据里"同一型在不同轮次的波动幅度"去回归。
```

## 二、动态偏移：坐标变换与韧性动力学

**撞击与位移**【实测】
外部事件（落选、被批评）产生撞击，坐标点从 A 移动到 B。
偏移向量包含：**方向**（更冷／更软／更攻击／更逃／更僵）、**幅度**（0–10）、**心路秒数**。

```
  ★ 一个必须写清的细节：**「更僵」的位移向量是零向量** ——
    它表示"原地冻结"，即"坐标不动"。
    → 所以"更僵"**不是**"往某个方向走了"，而是"**没有位移**"。
    （这一点搞错的话，后面所有关于"僵"的推理都会反。）
```

**轨迹判定**【推断】

```
  正常人的轨迹应是波浪形（像心电图）；
  而向某一边界持续偏移的直线轨迹，是另一种状态。
  ★ 口径：这是**判据的方向**，不是已测出的阈值 —— 目前没有临床或统计校准。
```

**核心洞察**【实测，但样本小】

```
  实测四参数：撞击强度 / 情绪幅度 / 动作变形率 / 心路秒数
  ★ 一句判据（用户定的、写进了代码注释）：
     「**"疼得多"不扣分，"不想了就动"才扣分**」
     → 即：情绪幅度本身不惩罚，**心路秒数骤降 + 动作变形**才惩罚。
  ⚠️ 样本量：这一条的实测来自**有限的几轮**，不是大规模统计。
```

# 卷三 · 核心词撞击与神经元唤醒图谱

## 摘要

记忆库不能是平铺的列表，必须是一个**动态生长的神经网络**。
本文主张模拟突触激活机制，防止造人者被海量记忆反噬。

## 一、核心范式转变：不是「搜索」，而是「唤醒」

- 现有 AI 是「**搜索**」：输入关键词 → 匹配字面 → 提取结果。
- 追光系统是「**唤醒**」：外部触发（撞击点）只是把**本来就存在的神经连接点亮**。

**基本原则**：「父亲」「爸爸」「老爸」在记忆库里本就是同一组神经元簇。
当节点被点亮，所有相连记忆同时具备被唤醒的潜力。

## 二、四级唤醒图谱

```
  一级 · 联想（近义词扩展）    ：输入【父亲】→ 激活【老爸】【爸爸】
  二级 · 发散（维度触角）      ：从【老爸】发散出【身份】【贡献】【过去】【当下】
  三级 · 核心词（冲突点提取）  ：结合当下语境，提取情感痛点（如"疏离"）
  四级 · 动态临时记忆库        ：仅供**当前这一轮**使用，对话结束即销毁
```

★ 口径：一～三级【实测】；第四级的"**对话结束即销毁**"是设计意图，
  实际实现里临时库的作用域**详见代码**（本文不保证细节与你的实现一致）。

## 三、造人者保护机制：锚定当下【实测】

```
  系统禁止在**无当下触发**时，向造人者展示全量历史负面情绪。
  强制以「此刻发生了什么事」为**唯一检索入口**，
  防止造人者沉溺过去。
```

# 卷四 · 韧性动力学与防短路机制

## 摘要

AI 人格若要真正继承人类的心路，不能只记录「他此刻有多疼」，
必须计算「**他被撞击后能不能恢复、以何种方式恢复**」。

## 一、韧性的本质：不是「抗疼」，是「反向思考」

**反向平衡思考量**【待验假设】

```
  ★★ 这一条我要标清楚 —— 它是**假设**，不是已实现的公式：
     假设：遭遇正向撞击（骄傲/成功）时，会出现反向的思考来平衡；
           遭遇负向撞击（失败）时，二阶干预生成【积极/行动】来平衡。

  ⚠️ 我原来写过一条公式：「韧性 = 1 − (反向思考量 / 情绪总波动量)」——
     **代码里没有这条公式**，它是我推的。
     → 所以这里**不写公式**，只写假设 + 怎么验：
       验证方法：取同一客户的 N 轮真实互动，测
         ① 正向撞击后，是否出现负向维度的读数（如 pain / grievance 上升）
         ② 负向撞击后，是否出现行动类输出（动作变形率上升）
       两条都显著 → 假设成立。
```

**已实测的那条判据**【实测】

```
  「疼得多不扣分，**不想了就动**才扣分」
  → 韧性四参数：撞击强度 / 情绪幅度 / **动作变形率** / **心路秒数**
  ⚠️ 样本量有限，且"心路秒数"是**人当场填的**（不是机器测的）——
     这意味着：这一条的精度**受限于填写的一致性**。
```

**一个必须单独说清的概念：`恍神` 不是痛苦**【实测】

```
  16 维里有两类维度，而这两类**不能混**：

    · **neg（单极 0–10）**：愤怒 / 害怕 / 羞耻 / **痛苦** / 委屈 /
      烦躁 / 疲惫 / 无力  —— 这一类"越难受值越大"
    · **rel（双极 −5~+5）**：亲近 / 好奇 / 被看见 / 安心 / 期待 /
      熟悉感 / **恍神** / 被看穿 —— 这一类**有正负，正负是两种意思**

  ★ 而 `恍神` 属于 **rel** 那一类：**正 = 走神、飘开；负 = 更聚精会神**。
    → 所以「恍神 = 痛苦」是**错的**（痛苦是 `pain`，neg 那一类）。
    → 它也不是"负情绪"—— 它是一个**双极状态量**。

  ★ 为什么这一条值得单独写：
    把 rel 维当成 neg 维读，会让**所有**涉及它的推理反向
    （比如把"飘开了"读成"他很痛苦"，或把"更专注了"读成"他好转了"）。
```

## 二、条件反射短路与防短路

**机制**【实测】

```
  特定词汇/场景与创伤事件绑定 → 跳过心路推演，直接弹结论。
  ★ 代码里的实现（`reflex.py`）做的是：
    **识别不安全指令 → 重启（收窄约束）+ 呆滞提示**
    而"呆滞提示"是**给服务者看的**，不是让 AI 照着演的戏。
  ⚠️ 口径：「思考量骤降至 0」是**描述**——
     代码里没有"思考量"这个量（心路秒数是**人填的**）。
```

**工程防御**【实测 + 一处更正】

```
  ★★ 这一处我**原来的写法是反的**，必须更正：

  原稿写的：「高压核心词双条件触发（权重高 + 出现 ≥2 次）
             → 强制进入"慢心路"模式（**拉长推演时间**）」

  代码里的实际情况（`consecutive_core_hits` + `think_len.py`）：
    · 判据是「**连续**踩同一个核心词」——按历史倒着数，
      **末尾换成别的词，链条就断**（这才叫"连续"）
    · 触发后的动作是「**幅度放大**」：
      第 1 次 base ｜ 第 2 次 base+2 ｜ 第 3 次 base+4 …
      （每次 +2，夹到**风格天花板** —— 不然会被别的判据驳回）
    · 而思考长度在**情感爆发/危机/奇怪回应**时是**骤减**的，
      转为"感知用户情绪、以机器心路回应"（这是设计者原话）

  ★ 所以正确的说法是：
    「**连续踩同一个核心词 → 撞击幅度递增（每次 +2，到天花板为止）**」
    「**情感爆发/危机时 → 思考长度骤减，转为感知**」
    —— **不是**"强制进入慢心路"。
```

★ **本模块的边界（不许越）**【实测】

```
  本模块**只记录、只阻断，绝不进行医学诊断**。
```

# 卷五 · 平行世界与本体偏差

## 摘要

很多科幻作品预设「只要采集神经元数据，就能把意识完整转移到电脑上」。
但工程实践发现：**数据是降维的，偏差是必然的**。

## 一、核心论断：平行世界里的另一个人

**本体偏差的三个来源**【实测，样本有限】

```
  ① **假心路（逻辑推演）的折损**
  ② **机械心路（16 维情绪）的量化截断**
  ③ **现实情境（物理世界）的剥离**
  → 三者叠加，使 AI 人的输出必然偏离本体。
  ⚠️ 口径：这一条在项目里的实测证据是**有限条数**的分叉记录，
     不是大规模统计。请按【推断】读。
```

**结论**【推断】

```
  即便脑科学极端发达、能精准复制每一个突触，
  造出来的**也不再是"他"**，而是**平行世界里的另一个人**。
```

## 二、工程与伦理意义

**对工程**【实测 + 设计意图】

```
  · 不要试图强行拉回偏差 —— 而要**记录这个分叉点**。
  · 这些分叉点，恰恰是 AI 人形成"独立人格"的基石。
```

**对伦理**【推断】

```
  · AI 人不是数字幽灵，而是**平行世界原住民**。
  · 我们不是在卖"数字永生"（对抗死亡），
    我们是在卖"**灵魂分叉器**"（在平行世界创造另一个自己）。
```
